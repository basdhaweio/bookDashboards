bookDashboards render harness

Loads /index.html against the local /data/bookdb.json and asserts the rendered numbers against the bundle itself. Run it any time via the dev server: py -m http.server 8123 --directory bookDashboards then open http://localhost:8123/tests/harness.html. Every check recomputes its expectation from the bundle, so ordinary data drift never fails it — only a rendering/math/lookup slip does.
